## 開啟與限制

雙擊交付資料夾內的 `index.html` 可本機開啟，請保留 `assets/`、`app.js`、`story.js`、`style.css` 在原位置。網站不依賴外部字型、CDN 或網路素材；完整播放需要影片下載完成。

瀏覽器通常禁止未操作前有聲自動播放：本片先靜音自動播放，輕觸「開啟聲音」後使用原影片音樂。若裝置阻擋靜音自動播放，提供「輕觸開始電影」按鈕。手機使用 `playsinline`，直式介面以模糊星光背景承托完整影片，不裁切人物。手機全螢幕依瀏覽器能力提供。

生日願望只使用目前瀏覽器的本機儲存，不上傳、不寄送。瀏覽器禁止本機儲存時會明確提示。切到背景會暫停，回來可按播放繼續。一般瀏覽器不支援 WebMCP 時不影響觀看。

## 測試

桌機 1440×1080 與手機直式 390×844 以 Chrome 實際載入驗證：自動播放、影片長度、暫停、章節跳轉、字幕、兩個互動、願望儲存、小卡、音樂／歌詞、聲音、結尾／重播、圖片載入及無水平溢出。詳細結果見 `test-results.json`。手機版以桌機瀏覽器模擬視窗驗證；尚未在實體 iPhone／Android 裝置逐機測試。
